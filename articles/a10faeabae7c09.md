# はじめに

技術関係のメモをNotionからObsidianに移行し、手持ちのAIサブスク(ChatGPT / Claude)だけで、追加課金なしにAIがメモを整理してくれる環境を作りました。この記事では、全機能の紹介ではなく「自分が便利だと思ったところ」に絞って構成を紹介します。
:::message
自分もobsidianを使い始めたばかりでまだまだ上手く活用できてない部分も多いですが、参考になる人もいるかもしれないと思って記事を書きました！
:::

# 前段: これまでNotionを使っていた

エンジニアになった当初(約4年前)から、勉強したことはNotionにメモしていました。Notion自体は便利だったのですが、続けるうちに2つの問題が出てきました。

1つ目は**管理の破綻**です。メモが増えるにつれて「このメモはどのページ・どのDBに書くべきか」を考えること自体が負担になっていきました。

2つ目は**そもそもメモを取らなくなった**ことです。生成AIに聞けばある程度のことは教えてくれるので、調べたことを記録する動機が薄れました。ただ、振り返ってみると「AIに何をどう聞いて、どう深掘りして、その瞬間何を理解したか」は自分だけのナレッジです。また、実際に手を動かして試行錯誤してわかったことも、書く場所が定まっておらず、結局メモに残さないという感じになっていました。一部はZennの記事にしていましたが、記事にするほどでもない小さな知見は消えていく状態でした。要するに「気軽にメモを取りづらい状況」になっていました。

NotionにもAI機能があり、うまく使えば増え続けるメモを管理できたかもしれませんが、課金はできるだけ抑えつつ気軽に技術系のメモを取るためにどうしたらいいかと考えて、obsidianを試すことにしました。
:::message
結果として技術系のメモはobsidianで管理することにしましたが、それ以外ではNotionを引き続き使っている情報もあるので、使い分けをするようになったって感じです。
:::

# 今回求めていたこと

- エンジニアとしての**技術的なメモを残してナレッジ化**したい
- それ以外のメモ(タスク管理など)まで全部を管理することは求めない
- **すでに課金しているChatGPT / Claudeのサブスク以外に追加課金せず**、AIでメモを効率的に管理したい

# Obsidianとは

Obsidianは、Markdownファイルをローカルフォルダに保存する方式のノートアプリです。ノート同士を`[[ウィキリンク]]`でつないでナレッジグラフを作れるのが特徴で、Notionなどと比較してローカルのファイルなので動作が軽いという声もあります。

自分にとって重要だったのは**ファイルベース**であることです。ノートの実体はただのMarkdownファイルなので、Claude CodeやCodexのようなAIコーディングツールがそのまま読み書きできます。つまり、すでに課金しているAIサブスクを「メモの整理係」として使える。ここがNotionとの一番の違いでした。

:::message
Notion MCPを使えばClaude Code等と連携できるじゃんって声もあると思いますが、MCP経由よりローカルのmdファイルを編集する方がAIにとってはトークン効率がいいはずですし、後述するようなメモ環境の構築はObsidianを使った方がやりやすいと感じました。
:::

# どのように管理することにしたか

## フォルダ構成

```
vault/
├── AGENTS.md          # AI向けの運用ルール(後述)
├── CLAUDE.md          # AGENTS.mdを参照するだけの薄いファイル
├── 00_Inbox/          # 書き殴りの一時置き場
├── 10_Daily/          # デイリーノート(YYYY-MM-DD.md)
├── 20_Notes/          # 恒久ノート(1ノート1アイデア、フロントマター必須)
├── 30_MOC/            # 技術領域ごとの索引(Map of Content)
├── 40_Ideas/          # 作りたいアプリ・サービスのアイデア
├── 50_Clips/          # Webクリップ(あとで読むキュー)
├── 60_Bookmarks/      # 気になるサービス・ツールのURLメモ
├── 90_Templates/      # ノートの雛形
└── _meta/             # タグ一覧・整理レポートなどの管理ファイル
```

Zettelkasten風の3層(書き殴り → 恒久ノート → MOC索引)をベースにしていますが、ポイントは**人間が丁寧に運用することを前提にしていない**ことです。雑に書いたメモも、Claudeのroutine(定期実行)でAIが週次で整理してくれるので、ゴミが溜まりづらい状態を保てます(routineの詳細は後述)。

Zettelkastenが何なのかを理解する必要はないですが、以下のような記事を参考として貼っておきます。
https://zenn.dev/levtech/articles/mach-auch-zettelkasten

週次のAIがどこのフォルダのどんなファイルを収集するかはroutine側のプロンプトで定義しているので、そのルールに合わせる形でメモを追加していくイメージです。

## 手書きメモは基本InboxかDaily

人間が書く場所は実質2つだけです。

| 書きたいもの | 書く場所 |
|---|---|
| その日の作業ログ・気づき・詰まったこと | `10_Daily/YYYY-MM-DD.md` |
| 日付に紐付かないメモ・調べたこと・アイデア | `00_Inbox/` に適当なファイル名で |

タグ・フロントマター・リンク・フォーマットは一切意識しません。すべてAIが後から付けるので、思考を止めずに書き殴ることを最優先しています。これにより、メモを書くというハードルが非常に低くなり、気軽にメモを取ることができます。
詳細は割愛しますが、下図のように設定を入れることで「新規ノートを追加するときは00_Inboxフォルダに格納」、「Dailyボタンで追加するファイルの格納フォルダやテンプレートの指定」という設定もでき、スムーズにメモを取ることができます。

## Chrome拡張のObsidian Web Clipperを使う
手書きでメモを取るだけでなく、webサイトの情報をメモにしたいというケースもあると思います。
そんな場合には、[Obsidian Web Clipper](https://obsidian.md/clipper)という公式のブラウザ拡張が便利で、自分は用途別に3つのテンプレートを使い分けています。テンプレートを切り替えて「Obsidianに追加」するだけで、簡単にデータを追加することができます。
![web clipper画面表示](/images/a10faeabae7c09/clipper-display.png =500x)
*Chromeの拡張機能でテンプレ変更できる画面*

以下のように設定で、新規テンプレートを追加し、どこの保管庫・どこのノートに、新規ノートを作成するのか・既存のノートに追記するのか、フロントマターのプロパティ、ノートの内容等について設定可能です。
これにより、webページを保存したい形式でobsidianに持ってくることが可能です。

### ① 読み終えて良かった記事を追加(定期AIの収集対象)
この記事は有益だったから、ノウハウとして残しておきたいって時に使います。
`50_Clips/`に`status: keep`のフロントマター付きで保存するテンプレートです。このフォルダの`status: keep`になっているファイルは、週次のAI整理で要点が抽出され、`20_Notes/`の技術ノートに昇華される仕組みになっています。


### ② あとで読みたい記事を追加

同じく`50_Clips/`ですが、こちらは`status: unread`で保存します。ポイントは**週次のAIは`unread`のクリップに絶対に手を付けないルール**にしていることです。まだ読んでいない(=価値判断していない)記事を勝手にナレッジ化されると、微妙な記事までノートに昇格してしまうためです。読んだ後の仕分けは人間がやります:

- 微妙だった → **ファイルを削除するだけ**(削除が正常動作の使い捨てキューという位置づけ)
- 良かった → `status`を`keep`に変えて一言メモ。次の週次整理でノート化される

未読とkeepの一覧は、Obsidianの`.base`ファイル(DB風ビュー機能)で確認できるようにしています。
以下が参考画像で、1件しかないですが、未読なのかkeepなのかを確認して、未読の内容をチェックすることができます。

### ③ 気になるサービスのサイトをメモとして残す

これは上の2つと役割が違って、「記事を読む」のではなく「このサービスを忘れないようにする」ためのブックマークです。`60_Bookmarks/`に1件1ファイルで保存し、クリップ時にポップアップの編集パネルで「なぜ気になったか」を一言書き加えます。溜まってきたら「ブックマークを整理して」とAIに頼んで既存のタグ体系で分類してくれるような想定です。

## AIチャットで理解を深めた内容をメモとして追加する

自分は普段ChatGPTを使ってAIと壁打ちしたり、[Chrome拡張のChatGPT拡張](https://chromewebstore.google.com/detail/chatgpt/hehggadaopoacecdllhhajmbjkdcmajg?hl=ja)で「開いているページの選択部分について質問」したりして理解を深めています。このチャット画面からAIに指示すれば、Obsidianのフォルダを指定してチャットの要約結果をメモとして追加できるので非常に便利です。

### chatGPT用のユーザーskill追加
さらにこの作業はよく発生するので、**Skillとして「どのフォルダに、どういう形式のメモを追加してほしいか」を定義**し、Codexのユーザー設定に追加しました。チャットの最後にSkillを呼び出すだけで、会話内容の要約からInboxへのmd追加までやってくれます。
```
cd ~/.agents/skills
```
→こちらのskillsディレクトリにskillを追加することで、ユーザー設定のSkillとして、ChatGPTやCodexからSkillを呼び出すことが可能です。自分はadd-obsidianというSkillを作成し、下図のように呼び出して、メモをInboxに追加してもらうことができます（Skillの作り方は一般的なものと同じで、AIに作らせることもできるので割愛します）。

### 注意点
`~/.agents/skills`にスキルを追加しましたが、ChatGPTでも最近（2026年7月頃）はChat、Work、Codexにモードが分かれており、Chatの場合は、スキルが使用できませんでした。今後はWorkとCodexがメインになっていきそうな気もしますし、Chromeの拡張機能を開くとWorkが動作していて、スキルが使用できたので、大きな問題にはならない気がしていますが、なぜかスキルが候補として表示されない事象に当たった人はChatになってないかをご確認ください。


## Claude Codeのroutinesで週次の自動整理

ここがこの仕組みの心臓部です。Claude Codeのスケジュールタスク(routine)に週次整理を登録しています。

設定は以下のような内容になっていますが、デスクトップアプリ上のClaude CodeでAIと壁打ちしつつ、こんなルーティン・定期タスクを作って欲しいと依頼すれば、簡単に作ってくれるはずです。

- **頻度**: 毎週日曜20:00
- **やること**:
  1. `00_Inbox/`と直近1週間の`10_Daily/`を読み、メモを「技術ノート→`20_Notes/`」「アイデア→`40_Ideas/`」に振り分けて昇華(1ノート1アイデアに分割、フロントマター・タグ付与、関連ノートへのリンク、MOCへの登録)
  2. `50_Clips/`の`status: keep`のクリップを要点抽出して技術ノート化

プロンプトの工夫として、routineには手順の詳細を直接書き込まず、**毎回`AGENTS.md`(Vaultの運用ルール)を読み直してから作業する**構成にしています。こうすると、運用ルールを変えたときにroutineを再設定する必要がありません。

また、定期実行は人間への対話的な確認ができないので、安全側に倒すルールを入れています:

- 判断に迷うもの(通常なら人間に確認するもの)は触らずそのまま残す
- git操作はしない(Obsidian Gitの自動commitに任せる)
- 実行結果のサマリーを`_meta/整理レポート/`にレポートとして残す(何を昇華したか、何を保留にしたか)

実際に動かしてみると、Inboxに書き殴ったメモがタグ付きの恒久ノートになり、MOCにリンクが張られ、レポートで「何をしたか」が確認できる状態になっていました。

:::message
Codexでも定期タスクを実行できるはずですが、Claudeを使っているのは、単に自分のトークンがClaude側が余りがちだっただけという理由で、Codexでも問題ないはずです。
Claude Code Routinesについては、いろんな人が記事やyoutubeを出してそうなので、よくわからない人は調べてみてください！
:::

# そのほかやっていること

## AGENTS.mdを用意

Vaultのルートに、フォルダ構成・フロントマターのスキーマ・タグ規約・整理手順などの運用ルールをまとめた`AGENTS.md`を置いています。CodexはAGENTS.mdをネイティブに読み、Claude Code側は`CLAUDE.md`から`@AGENTS.md`でインポートしているので、**どちらのAIツールを使っても同じルールが適用されます**。

## Obsidianに関するSkillsを追加
以下のリポジトリがObsidianを操作するための便利アプリとしてObsidian公式の人が公開してくれているSkillなので、AIがうまく動作しやすくなるかもと思って入れてみました。
https://github.com/kepano/obsidian-skills

なくても問題ないと思いますが、一応以下のようなSkillが用意されているようなので、ご参考までに。

| スキル | 何ができるか | 使う場面 |
|---|---|---|
| `obsidian-markdown` | ウィキリンク・コールアウト・埋め込み・フロントマター等のObsidian記法 | ノートの新規作成・編集全般。記法の参照元 |
| `obsidian-cli` | 起動中のObsidianアプリをCLIから操作(検索・バックリンク・プロパティ一括変更・プラグイン開発) | Obsidianを起動した状態での補助操作。基本はファイル直接編集で足りる |
| `obsidian-bases` | `.base` ファイル(ノートのDB風テーブル/カードビュー)の作成・編集 | ノート一覧を表形式で眺めたい時。**ビュー結果はAIから読めない**ので人間の閲覧用 |
| `json-canvas` | `.canvas` ファイル(マインドマップ・図解)の作成・編集 | アーキテクチャ図や概念整理を視覚化したい時 |
| `defuddle` | WebページをクリーンなMarkdownに変換して取得 | 調査メモ作成時のWebページ取り込み(WebFetchより省トークン) |

## Obsidian Gitで自動コミット&push

コミュニティプラグインのObsidian Gitで、15分間隔の自動commit & pushを設定しています。同期・バックアップはGitHubのプライベートリポジトリのみで、iCloud同期やObsidian Syncは使っていません。AIが整理した結果も自動でGitHubに積まれていくので、変更履歴がそのまま証跡になります。

## Obsidianの拡張機能

Obsidianはコミュニティプラグインが豊富で、自分は今のところObsidian Git、Web Clipper(拡張機能)、Bases(ノートのDB風ビュー)あたりを使っています。

# できていないこと

Mac上での閲覧・編集がメインで、**iPhoneでのメモの編集・閲覧**は今のところ構築していません。GitHubのプライベートリポジトリには全部入っているので、GitHubアプリやSafariから見ることはできますが、iPhoneのObsidianアプリからの編集・閲覧はできない状態です。初めはできるようにしたかったのですが、PCで作業することがほとんどなので、現状で問題なしと判断しました。

検討した同期方法と断念した理由:

- **Obsidian Sync**: 一番確実だと思いますが、お金がかかるため断念(今回のテーマは追加課金なし)
- **iCloud同期**: Mac + iPhoneなので当初有力でしたが、iCloud Drive上にVaultを置くと**VSCodeやClaude Codeからファイルを読み込もうとするとpermission errorが出てしまい**、解決できなかったので断念しました(あまり時間はかけていないので解決方法はあるかもしれません)。AIに操作させるうえで障害になる可能性があったので不採用としましたが、すでにiCloudを使っていてiPhone同期をしたい場合は検証する価値はあると思います(参考記事: https://zenn.dev/harieshokunin/articles/5a827bee5d2355 )

# まとめ

まだまだ運用するにあたって課題は出てくると思いますが、**メモを気軽に追加でき、AIがいい感じに整理してくれる環境**を構築できた気がします。課題が出てきても、ファイルベースなのでAIに指示して整理し直したり、routineを改善したりできます。追加課金なしでここまでできたのはすごく嬉しいポイントです。

Obsidianはカスタマイズ性が高く、極めようとすると大変ですが、今回の構成も「自分がどうメモを取りたくて、どう管理してくれると嬉しいか」をAIと壁打ちしながら作ったものです。同じやり方で、自分以外の人でもその人に合ったメモ環境を構築できると思います。
